# Dirección visual

## Principios

- Mostrar alivio y claridad, no culpa.
- Mostrar situaciones reales argentinas.
- Mantener espacio para texto.
- Evitar exceso de números.
- Usar una sola idea por pieza.

## Composición

Priorizar:
- foco central
- profundidad suave
- pocos elementos
- jerarquía visual fuerte

## Inspiraciones

- editorial lifestyle
- minimalismo cálido
- producto como resolución

## Consistencia con Nivva

No usar:
- gráficos bursátiles
- lujo
- billetes exagerados
- dashboards complejos
